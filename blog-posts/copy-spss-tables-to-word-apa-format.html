How to Copy SPSS Tables into Word in Perfect APA 7 Format (No Messy Screenshots)

You ran the analysis. Now your SPSS output looks nothing like your dissertation template. Here is the exact copy-paste + APA 7 reformatting workflow markers actually want to see — no blurry screenshots, no gridlines, no p = .000.

Why Do SPSS Screenshots Lose Marks?

Supervisors and second markers do not deduct marks because they dislike SPSS. They deduct marks because screenshots break every APA rule at once. An SPSS screenshot APA presentation typically fails on five counts:

  • It is an image, not text. Markers cannot select numbers, Turnitin cannot read it, and it pixelates when printed. Anything pasted as a picture also ignores your Word font and line spacing.
  • It keeps SPSS gridlines. APA 7 allows only horizontal rules — a top rule, a header rule, and a bottom rule. SPSS uses full boxes and vertical dividers, which APA explicitly forbids.
  • It shows too much. Raw SPSS output includes footnotes like “a. Lilliefors Significance Correction” and three-decimal defaults such as 4.23567 that no APA table should ever show.
  • It copies SPSS variable names. Markers want Perceived Stress (M = 22.40), not PSS_Total_REV_v2.
  • It mishandles p-values. SPSS prints Sig. .000. APA never allows p = .000 — the correct form is p < .001.

What Does a Correct APA 7 Style Table Look Like?

Before you copy anything, memorise this five-second APA 7 checklist from the Publication Manual (7th ed., Chapter 7) and Purdue OWL. Every APA format SPSS table you submit must pass it:

  1. Horizontal rules only. No vertical lines, no cell grid, no shaded background. Keep a thick top rule, a thin rule under the column headings, and a thick bottom rule. Add one extra thin rule only to separate a total row or groups if essential.
  2. Number + title on top. Table 1 in bold on its own line, then the title in italics on the next line, e.g. Descriptive Statistics for Wellbeing Scores by Group. Keep it short but informative.
  3. Same font and size as text. Usually Times New Roman 12 pt or Calibri/Arial 11 pt, single or double-spaced to match your university template. Do not leave SPSS default Courier or tiny 8 pt text.
  4. Consistent decimals. Means, SDs, t, F, r and confidence limits: two decimals. Exact p-values: two or three decimals. Never vary within a column.
  5. Italics and spacing for statistics. Italicise M, SD, t, F, p, r, d, χ², N, n. Use spaces around = and <: p = .032, t(58) = 2.45, p < .001. Drop the leading zero for values that cannot exceed 1 (p, r), keep it where they can (M, SD, t).
  6. Note below. Start with italic Note. followed by a period, then explain abbreviations, *p < .05. **p < .01, sample sizes, and scale ranges in plain sentence case.
Never report SPSS “Sig. .000” as p = .000. SPSS rounds to three decimals. Anything showing .000 means p < .001. Writing p = .000 tells your marker you copied without understanding — one of the fastest ways to lose easy marks.

Method 1: How to Copy an SPSS Table into Word (Best for 1–3 Tables)?

This is the fastest way to learn how to copy SPSS table into Word APA format when you only need a few tables. It preserves editability so you can reformat to APA in Word. Works identically in SPSS v27, v28, v29 and v30 on Windows and Mac.

1Select only the table you need in Output Viewer. In SPSS, run your analysis first. In the left outline pane, click the table icon (e.g. Descriptives, Correlations, Independent Samples Test) so it highlights. Click once on the table itself in the right pane — you should see a red outline. Do not select the whole output; copying everything imports Log notes and warnings you do not want.

2Copy Special as Formatted Text. Right-click the selected table → Copy Special (or Edit → Copy Special). In the dialogue, untick Image and tick Formatted Text (RTF) or Text. On Mac, choose Rich Text. Click OK. Why not plain Ctrl+C? Plain copy often defaults to an image or keeps SPSS pivot formatting that breaks in Word. Copy Special forces an editable table object.

3Paste Special in Word. In Word, place your cursor where the table belongs (usually after the paragraph that first mentions it). Go to Home → Paste → Paste Special → Formatted Text (RTF) or right-click → Paste Options → Keep Text Only if RTF brings heavy shading. You should now have a real Word table you can click inside — if you cannot place your cursor in a cell, you pasted a picture; undo and repeat step 2.

4Strip SPSS formatting immediately. Select the table → Table Design → Borders → No Border. Then Home → Clear All Formatting if font looks wrong, and set it to your dissertation font. Remove grey cell shading via Table Design → Shading → No Color. Delete empty SPSS spacer columns and footnote rows such as “a. Computed using alpha = .05”.

5Keep only the columns you will discuss. SPSS prints far more than APA needs. For descriptives keep Variable, n, M, SD, Min, Max. For correlations keep r and p only. For t-tests keep M, SD, t, df, p, d. Delete Std. Error, Skewness details, Levene’s F unless your methods chapter explicitly requires them. Rename variables to reader-friendly labels.

6Apply the three APA rules. Select header row → add a top border (2¼ pt) and bottom border (½ pt) via Borders → Top Border / Bottom Border. Select the last data row → add a bottom border (2¼ pt). Centre numeric columns, left-align the first label column. Set consistent decimals (select column → right-click → Format Cells equivalent by retyping to 2 dp).

7Add number, title, and note. Above the table type Table 1 then on the next line Descriptive Statistics for Anxiety and Sleep Quality (N = 120). Below the table type Note. plus your explanation. Refer to it in text: “As shown in Table 1, …” — APA requires every table to be mentioned before it appears.

Done correctly, this takes 5–8 minutes per table after one practice run. Save your finished APA table as a Word Quick Part or Table Style so the next ten tables take two minutes each. If you need to report descriptive statistics in SPSS, build that template first — you will reuse it most.

Method 2: How to Export SPSS Output to Word (Best for Whole Chapters)?

When you need to import SPSS output into Word in bulk — say 15 tables for a results chapter — exporting beats copying one by one.

  1. In SPSS Output Viewer (.spv open), tidy the left outline: right-click and hide Log, Notes, and Warnings you do not want exported. Rename key tables by double-clicking their outline labels.
  2. Go to File → Export. In SPSS v29/30 the dialogue shows Objects to Export: All visible / Selected / All. Choose All visible if you hid junk, or select specific items holding Ctrl.
  3. Under Type choose Word/RTF (*.doc, *.docx). Tick Include charts as images if you want boxplots too. Choose a fresh folder — SPSS creates one .docx containing every table in order.
  4. Click OK, open the .docx in Word, and immediately Save As with a new name so you never overwrite raw output.
  5. Now reformat every table exactly as in Method 1: remove verticals, fix fonts, trim columns, fix p = .000 → p < .001. Export does not produce APA tables automatically — it just moves editable tables faster.

Which method should you use? Use Copy Special for final tables going into your dissertation. Use Export for drafting, supervisor checks, or when you need to archive full output as an appendix. For guidance on what to keep versus cut when you write up, see our guide to reporting SPSS results in APA 7.

SPSS v29/30 tip: If File → Export → Word exports blank pages, update SPSS to the latest fix pack and close Word first. SPSS cannot overwrite an open .docx. On university lab PCs where Export is disabled, Copy Special still works — use Method 1.

How to Reformat Any SPSS Table to APA 7 in Word (6-Minute Fix)?

Copying is only half the job. This is the exact reformatting sequence we use when students send us messy APA format SPSS tables:

1. Fix borders (30 seconds)

Select whole table → Table Design → Borders → No Border. Then select the header row → Borders → Top Border (thick) + Bottom Border (thin). Select the final row → Bottom Border (thick). If you need to separate groups (e.g. Male/Female blocks), add one thin mid-rule only. Never re-add verticals or outer boxes to “make it clearer” — APA markers read verticals as an error.

2. Fix font, size and alignment (60 seconds)

Set the table to your body font — Times New Roman 12 pt, Calibri 11 pt, or Arial 11 pt per APA. Make the header row bold, sentence case. Left-align the stub (first) column, centre or decimal-align numbers. Turn on Table Properties → Row → Allow row to break across pages: OFF and Repeat header row for long tables. Set AutoFit → AutoFit to Window so the table respects 1-inch margins.

3. Fix decimals and labels (2 minutes)

Round every M, SD, t, F, r, β, CI to two decimals. Round exact p to three decimals (or two if your department allows), except p < .001. Replace SPSS headings: Mean → M, Std. Deviation → SD, Sig. (2-tailed) → p, Pearson Correlation → r. Italicise those symbols in both header and note. Remove the leading zero for p and r (p = .042, r = .31) but keep it for M, SD, t (M = 0.45).

4. Fix p-values from SPSS (1 minute)

Find every “.000” in your pasted table. Replace with “< .001”. Check spacing: p < .001, not p<.001. Add asterisks only if your table uses them, and define them in the note: *p < .05. **p < .01. ***p < .001. Never mix exact p and asterisks without explanation. For full sentence templates, see how to interpret regression in SPSS.

5. Add Table number, title and Note (90 seconds)

APA order matters: Table 1 (bold, flush left) → Title in italics and title case on the next line → your clean table → Note. (italic + period) below. Example note: Note. N = 120. M = mean; SD = standard deviation. Scores range 0–40; higher scores indicate greater stress. **p < .01.

How to Edit a Boxplot in SPSS for APA Style?

Tables must be editable Word tables, but figures stay as images. The mistake students make with edit boxplot SPSS APA style tasks is exporting the default SPSS chart — grey background, coloured 3D boxes, tiny labels — straight into Word. Fix it in Chart Editor first; it takes three minutes:

  1. Open Chart Editor: Double-click the boxplot in Output Viewer. A new Chart Editor window opens. If double-click does nothing, right-click → Edit Content → In Separate Window.
  2. Remove chart junk: Click the grey background → Properties → Fill → No fill / white. Click gridlines → Delete. Click the boxes → Fill → white or light grey with solid black borders. APA prefers black-and-white or greyscale; avoid SPSS default blue/red/green.
  3. Fix text: Click axis labels → set to 10–12 pt Arial or Calibri, black. Rewrite variable labels (“Anxiety_Total” → “Anxiety (GAD-7 score)”). Remove the default SPSS title inside the chart — your Figure title goes in Word, not in the image.
  4. Fix scale: Double-click the y-axis → set sensible min/max (e.g. 0–21 for GAD-7, not −5 to 45). Make sure median lines are clearly visible. For grouped boxplots add a simple monochrome legend.
  5. Copy cleanly: Close Chart Editor → right-click chart → Copy as → Image (EMF/metafile) for sharpest print quality. Paste into Word, centre it, and resize by dragging corners only (never stretch).
  6. Add APA Figure caption: Below the image type Figure 1 (bold) then Boxplot of Anxiety Scores by Sleep Group (italic, title case) on the next line, then Note. explaining n per group, circles = outliers, line = median.

The same workflow applies to bar charts, histograms, and scatterplots: white background, plain fonts, no 3D, no SPSS footnote text burned into the image. If your chart still looks fuzzy after paste, re-copy as EMF rather than JPG — EMF stays vector-sharp when Word exports to PDF.

Final APA 7 Checklist Before You Submit

Run this checklist for every table and figure — it mirrors what external examiners check in under two minutes:

  • ☐ Is it a real editable Word table (not a screenshot)? Can you click inside every cell?
  • ☐ Only horizontal lines — no verticals, no full grid, no grey shading?
  • ☐ Table X bold + italic title above; Note. below with N, abbreviations, and *p definitions?
  • ☐ Consistent decimals (2 dp; 2–3 dp for p), p < .001 not p = .000, leading zero dropped for p, r?
  • ☐ Statistics italicised (M, SD, t, F, p, r, d), spaces around = and <, reader-friendly labels?
  • ☐ Every table/figure mentioned in text before it appears (“As shown in Table 1 …”)? Numbered in order?
  • ☐ Boxplots/charts: white background, 10–12 pt labels, EMF quality, Figure X + italic title + note?
  • ☐ Table fits margins, repeats header if split, no orphan footnote rows from SPSS?

If you tick all eight, your tables will look more professional than 90% of quantitative dissertations submitted this year — and you will avoid the “poor presentation of statistical results” comment that drags many 2:1s down to 2:2s.

Final Thoughts

Learning how to import SPSS output into Word APA style is not about mastering SPSS — it is about translating SPSS into something humans want to read. Copy as editable text, strip the grid, keep three horizontal lines, fix decimals and p-values, and label everything clearly.
