How to Write Up Regression Predictors Table in APA 7 (SPSS Output Solved)

Struggling with how to report individual predictors regression APA SPSS style? Here is the exact table layout, template sentence, and worked examples for B, SE, beta, t, p — ready for your dissertation Chapter 4.

how to report individual predictors regression APA SPSS regression table APA from SPSS report B beta t p APA 7 SPSS

If you have run a multiple regression in SPSS, the hardest part is not clicking Analyze > Regression > Linear — it is knowing how to report individual predictors regression APA SPSS examiners will accept. Most dissertation students either paste a raw SPSS screenshot or write one vague sentence like “all variables were significant.” Both lose marks.

This guide solves it step by step. You will learn what a correct regression table APA from SPSS must contain, how to report B beta t p for each predictor, and how to write the paragraph that goes with the table. If you need the bigger picture first, see our guides on how to interpret regression in SPSS and how to report SPSS results in APA 7.

The Copy-Paste Template Sentence

Use this order every time: overall model first, then individual predictors. Fill the brackets from your SPSS output:

A multiple linear regression was conducted to predict [dependent variable] from [IV1, IV2, IV3]. The overall model was significant, F([df regression], [df residual]) = [F], p [< .001 / = .xxx], R2 = [.xx], adjusted R2 = [.xx]. As shown in Table 1, [IV1] was a significant positive predictor (b = [B], SE = [SE], β = [.xx], t([df]) = [t], p = [.xxx], 95% CI [[LL], [UL]]), whereas [IV2] was not significant (b = [B], SE = [SE], β = [.xx], t([df]) = [t], p = [.xxx], 95% CI [[LL], [UL]]).

That one paragraph already covers report B beta t p correctly: unstandardized coefficient with its standard error, standardized beta for comparison, test statistic with degrees of freedom, exact p-value, and confidence interval. The rest of this article shows you where each number comes from.

Report Model Summary (R²) and ANOVA (F) First

Examiners expect the story in this order: 1) Did the model work at all? 2) Which predictors drove it? Never start with individual predictors before you establish overall fit.

From SPSS you need three tables, but you only report two ideas in text:

  • Model Summary: report R2 and adjusted R2. Example: “The model explained 47% of the variance in dissertation stress (R2 = .47, adjusted R2 = .45).” Adjusted R2 matters when you have multiple predictors because it penalises complexity.
  • ANOVA: report the omnibus F test. Example: “F(3, 116) = 34.12, p < .001.” The first df is number of predictors; the second is N – k – 1 (sample minus predictors minus 1).
  • Coefficients: this becomes your APA Table 1. Do not paste it as-is — rebuild it (see below).

A complete opening sentence looks like this: “A multiple regression predicting job satisfaction from workload, supervisor support, and autonomy was significant, F(3, 116) = 34.12, p < .001, R2 = .47, adjusted R2 = .45.” Only after that sentence do you discuss individual b, β, t, and p values. For a deeper walkthrough of R2 and F, read how to interpret regression in SPSS.

How to Read the SPSS Coefficients Table

Open the SPSS output titled Coefficientsa. Each row is one predictor plus the Constant (intercept). Each column maps directly to your APA table:

SPSS ColumnWhat It MeansHow to Report in APA
B (Unstandardized)Change in DV for a 1-unit change in that IV, holding others constant. Original units.Report as b = 0.52. Always pair with SE and 95% CI.
Std. Error (SE)Precision of B. Smaller = more precise estimate.Report as SE = 0.09. Never omit it.
Beta (Standardized)Same effect in standard-deviation units. Lets you compare predictors.Report as β = .48. Use to say “strongest predictor.”
tB divided by SE. Tests whether B differs from zero.Report as t(116) = 5.78. df = residual df from ANOVA.
Sig. (p)Two-tailed p-value for that predictor.Report exact p (e.g., p = .024) or p < .001. Never write p = .000.

Practical tip: if your output shows Sig. = .000, that is SPSS shorthand for p < .0005. In APA you must write p < .001, never p = .000. Likewise, round B, SE, β, and t to two decimals, but report p to three decimals (APA 7, §6.36). Keep variable labels short and human-readable — “Supervisor Support” beats “SUP_Support_MEAN_v2”.

3 In-Text Examples: Significant, Non-Significant, and Multiple Predictors

You must describe every predictor in text, not just point at the table. Follow the pattern direction + size + evidence: say whether it increased or decreased the outcome, give b and β, then give t and p as proof.

1. Significant predictor example

Supervisor support was a significant positive predictor of job satisfaction, b = 0.52, SE = 0.09, β = .48, t(116) = 5.78, p < .001, 95% CI [0.34, 0.70]. Each one-point increase in supervisor support was associated with a 0.52-point increase in job satisfaction when workload and autonomy were held constant.

Why this works: it interprets b in real scale points, cites β = .48 as a large effect, and the CI excludes zero, confirming significance.

2. Non-significant predictor example

Autonomy was not a significant predictor of job satisfaction when controlling for the other variables, b = 0.08, SE = 0.11, β = .06, t(116) = 0.73, p = .467, 95% CI [-0.14, 0.29].

Why this works: it still reports the full statistics — a common examiner complaint is students hiding non-significant results. The CI crossing zero visually confirms p > .05. State it once and move on; do not apologise or speculate at length in Results.

3. Multiple predictors paragraph (dissertation-ready)

A multiple regression predicting job satisfaction from workload, supervisor support, and autonomy was significant, F(3, 116) = 34.12, p < .001, R2 = .47. Supervisor support emerged as the strongest predictor (β = .48, p < .001), followed by workload, which negatively predicted satisfaction (b = -0.31, SE = 0.09, β = -.28, t(116) = -3.61, p < .001, 95% CI [-0.49, -0.14]). Autonomy did not contribute uniquely (b = 0.08, SE = 0.11, β = .06, t(116) = 0.73, p = .467). See Table 1.

Rank predictors by absolute β when you use words like “strongest.” Here |.48| > |.28| > |.06|, so the ordering is defensible. Always end with “See Table 1” so the reader connects text to table.

Standardized (β) vs Unstandardized (b): Which to Emphasise?

Students often ask whether to report B beta t p all together or pick one. Answer: report both, but use each for a different job.

UseWhenExample Wording
Unstandardized b + SE + CIInterpreting practical meaning in original scale; building the regression equation.“A 1-hour increase in study time predicted a 0.52-point increase in exam score.”
Standardized βComparing which predictor matters most within the same model.“Motivation (β = .48) was a stronger predictor than anxiety (β = -.28).”

Two warnings: never compare b values across differently-scaled predictors (e.g., income in pounds vs age in years) — that is what β is for. And never compare β across different samples or studies with different variances — use b with CIs for that. If your supervisor asks “what does this mean in plain English?”, answer with b. If they ask “which hypothesis was most supported?”, answer with β.

Multicollinearity (VIF) Note: One Sentence That Saves Marks

Because you are interpreting individual predictors, you must show they are not redundant with each other. In SPSS, tick Collinearity diagnostics before running the model, then add one sentence:

Multicollinearity was not a concern; tolerance values ranged from .70 to .85 and all VIFs were below 2.5 (maximum VIF = 1.42).

The rule most UK/US universities accept: VIF < 5 is acceptable, VIF < 2.5 is ideal; tolerance > .20. If a VIF exceeds 5, do not silently report the coefficients — either combine or remove the overlapping predictor and re-run, then disclose what you did. Examiners specifically check this when two predictors are conceptually similar (e.g., “stress” and “anxiety”). You can place the VIF sentence right before the predictor paragraph or fold it into the table note as we did above.

7 Mistakes That Cost Marks

  1. Pasting an SPSS screenshot. Screenshots are not APA tables. Rebuild the table with a number, italic title, and note.
  2. Writing p = .000. SPSS truncates; APA requires p < .001.
  3. Reporting only β without b and SE. Readers need b to understand real-world size and to replicate your equation.
  4. Forgetting degrees of freedom. t(116) = 5.78 is complete; t = 5.78 is not. Copy residual df from the ANOVA table.
  5. Interpreting the Constant. Unless zero is meaningful on all your scales, do not discuss the intercept beyond listing it in the table.
  6. Claiming causation. Regression shows unique association while controlling for other variables — not proof that X “causes” Y. Use “predicted” or “was associated with.”
  7. Hiding non-significant predictors. List every predictor entered in the model, significant or not. Selective reporting is a red flag for examiners.

Dissertation Checklist Before You Submit

  • Overall model reported first: F(df1, df2), p, R2, adjusted R2.
  • Table numbered (Table 1) with italicised title above the table.
  • Columns: Predictor, b, SE, β, t(df), p, 95% CI.
  • b/SE/β/t to two decimals; p to three decimals (or < .001).
  • Leading zero omitted for β, p, R2 (e.g., .48 not 0.48); kept for b, SE, t, CI.
  • Statistical symbols italicised (b, β, t, p, F, R2).
  • VIF/tolerance checked and stated in text or table note.
  • Every predictor described in text with direction, size, and full statistics.
  • Table note defines all abbreviations and gives sample size.

Final Thoughts

Learning how to report individual predictors regression APA SPSS style comes down to one habit: model first, predictors second, table plus text always. Open with F and R2, then present a clean regression table APA from SPSS with b, SE, β, t, p, and 95% CI — and describe each predictor in words so a non-statistician can follow your argument.

If you can write “supervisor support positively predicted satisfaction (b = 0.52, β = .48, p < .001) while autonomy did not (p = .467)” without looking back at SPSS, you have mastered it.
